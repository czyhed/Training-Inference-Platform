# 优云社区镜像与小型视觉基模接入设计

**日期：** 2026-09-02  
**状态：** 待用户审核  
**范围：** 视觉理解微调环境发现、兼容性探针、小样本验收与优云实例回收

## 背景与目标

当前优云视觉模型目录已经映射了 Qwen2.5-VL 72B、Qwen3-VL 32B FP8 和 Qwen3-Omni 30B，但这些模型显存和费用较高，不适合作为首次链路验证。社区镜像列表中已发现 `LLaMAFactory-WebUI`，其声明支持 Qwen2-VL 多模态 SFT、LoRA/QLoRA，但仍需要真实探针验证，不能仅按镜像名称判定可用。

本次优化建立“镜像发现 → 兼容性探针 → 小样本训练 → 正式验收”的分阶段流程，并补充 2B/3B/4B/7B/8B 视觉基模，让平台能够优先用低成本模型完成链路验证，再逐步升级到大模型。

## 推荐模型梯度

| 阶段 | 模型 | 主要用途 | 建议显存 | 状态策略 |
|---|---|---|---:|---|
| P0 | Qwen2-VL-2B-Instruct | 最低成本数据、Processor、LoRA/QLoRA 回归 | 16-24GB | 首个探针与训练验收模型 |
| P0 | Qwen2.5-VL-3B-Instruct | 默认首验模型，通用图像描述、OCR、视觉问答 | 24GB | 优先绑定 `LLaMAFactory-WebUI` 探针 |
| P1 | Qwen3-VL-2B-Instruct | 新模板轻量验证 | 16-24GB | 通过 Qwen3 模板探针后开放 |
| P1 | Qwen3-VL-4B-Instruct | 效果与成本平衡 | 24GB+ | 通过探针后开放 |
| P1 | Qwen2-VL-7B / Qwen2.5-VL-7B | 迁移已有 Qwen2-VL 数据、提高效果 | 24GB QLoRA，推荐 48GB | 需缓存或共享目录确认 |
| P2 | Qwen3-VL-8B-Instruct | 更复杂文档、图表和视觉推理 | 48GB+ | 小样本通过后开放 |
| P2 | Qwen3-VL-32B-Thinking-FP8 | 高质量推理 | 48GB+ | 仅远端探针，不作为首验 |
| P2 | Qwen2.5-VL-72B-Instruct / Qwen3-Omni-30B | 大模型生产候选 | 80GB+ | 最后验收，禁止默认推荐 |

`Qwen3-vl-abliterated`、ComfyUI、Qwen-Image、Stable Diffusion、FLUX、TTS 和视频类镜像不进入视觉理解微调候选。前者偏推理/视频处理，后者属于图像生成、语音或视频工作负载。

## 社区镜像策略

首选 `LLaMAFactory-WebUI` 作为隔离验证镜像。目录记录必须包含镜像 ID、名称、来源、CUDA、PyTorch、Python、支持模型家族、训练能力、推荐显存、验证状态、最近探针时间和失败原因。`LLaMA-Factory-YingHuoAI` 仅作为备选，未通过 Qwen-VL 多模态探针前不得标记为可训练。

镜像状态使用以下状态机：

`未验证 → 探针通过 → 小样本训练通过 → 正式验收通过`

任何阶段失败均进入 `不兼容` 或 `待重试`，并保留结构化错误，不允许前端显示“可用”而绕过探针。

## 兼容性探针

探针分为无实例静态检查和实例内真实检查：

1. 静态检查：镜像元数据、模型 Repo ID、共享模型路径、显存建议、模板映射。
2. 远端检查：Python、PyTorch、CUDA、GPU、`transformers`、`peft`、`bitsandbytes`、`llamafactory` 版本。
3. 模型检查：加载 Config、Tokenizer、Processor，验证图片预处理、`<image>` 消息模板和 LLaMA-Factory 模板。
4. 训练能力检查：LoRA/QLoRA 注入、单张图片 forward/backward、loss 为有限值、显存峰值可记录。

探针结果统一返回 `checks[]`、`passed`、`blockingReason`、`recommendedTuningMode`、`estimatedVramGb` 和 `logs`，供 API、前端和审计使用。

## 小样本验收

探针通过后，使用固定视觉理解训练集子集执行最小训练：训练样本不超过 10 条，验证样本 5 条，固定随机种子、图片最大像素、batch 和梯度累积。验收只判断链路完整性：数据加载、Processor、forward/backward、loss、日志、Adapter、Best/Final manifest 和任务结束状态，不把小样本指标当作生产效果结论。

默认顺序为 `Qwen2.5-VL-3B + QLoRA`，失败后降级为 `Qwen2-VL-2B + LoRA/QLoRA`；Qwen3-VL 模型不得因体量小而跳过模板探针。

## 优云生命周期与费用保护

创建实例前必须实时检查库存、显存和价格，并展示预算确认。实例只允许由探针或已确认的小样本任务创建。成功、失败、停止、超时和连接中断都必须进入统一释放流程；释放失败时保留远端实例句柄并阻止重复启动，直到释放重试成功。释放后再次查询实例，确认实例已消失或处于已释放状态。

## API 与前端边界

后端新增只读社区镜像目录、镜像探针和探针报告接口；现有视觉模型注册、训练和推理接口保持兼容。前端在模型选择器中展示模型梯度、镜像兼容状态、推荐显存、训练模式和阻塞原因，只允许选择探针通过且资源满足的组合；提供“探针”“小样本验证”“正式训练”三个明确动作。

## 验收标准

- 至少一个社区镜像能够完成 Qwen2.5-VL-3B 或 Qwen2-VL-2B 的 Processor、LoRA/QLoRA 和最小 forward 探针。
- 小样本训练能生成 Adapter、Best/Final 元数据、Loss 和日志。
- Qwen3-VL-2B/4B 在模板未验证前显示为待探针，不得误报可训练。
- 训练失败能定位到镜像、依赖、模型、模板、显存或实例生命周期阶段。
- 优云实例在成功、失败、停止和释放重试路径下均可回收，释放后实例数量恢复为零。
- 未执行真实验收前不创建付费实例；所有后端、前端和 TypeScript 回归测试通过。

## 非目标

本阶段不引入新的模型家族，不把推理专用镜像改造成训练镜像，不自动下载大型模型，不改变现有数据集格式，也不开放未经探针验证的正式训练入口。
