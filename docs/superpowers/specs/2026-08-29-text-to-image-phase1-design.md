# 文生图阶段一设计

日期：2026-08-29

## 目标

把当前“文生图”占位入口升级为可配置、可校验的资产工作区，为后续优云推理和 LoRA/QLoRA 微调提供稳定的数据、模型和服务配置契约。

阶段一只做本地可验证的配置与校验，不启动本机 GPU 推理、不创建真实优云实例、不产生云资源费用。

## 范围

### 1. 文生图数据集

- 支持 JPG、JPEG、PNG、WebP 批量上传。
- 单张图片不超过 20MB，单个数据集最多 200 张。
- 支持图片预览、文件名、尺寸、大小和处理状态。
- 每张图片保留可编辑 Caption；初始 Caption 可由文件名生成，自动 Caption 只作为后续优云任务能力。
- 生成并保存规范化 `metadata.jsonl`，至少包含图片相对路径和 Caption。
- 数据集状态沿用现有 `failed`、`ready`、`published` 生命周期；校验失败不得进入训练选择器。
- 阶段一不承诺真实图片语义质量，只校验文件格式、路径安全、图片可解码性、Caption 非空和记录数一致性。

### 2. 文生图模型目录

- 基座模型和训练完成 Adapter 分组展示。
- 基座模型记录 Repo ID、架构标签、推荐镜像和优云可用性。
- Adapter 记录来源任务、基座模型、Adapter 版本（Best/Final）和产物状态。
- 阶段一只允许选择明确支持的模型；不把任意 Repo ID 标记为可部署。
- 文生图训练方式显示为 `LoRA` 和 `QLoRA` 两个选项。
- `LoRA` 是默认稳定路径；`QLoRA` 作为优云高级选项，只对经过镜像和模型兼容性验证的组合开放。

### 3. 文生图服务配置

- 创建页选择基座模型或训练完成 Adapter、推理镜像、区域、可用区、GPU 规格、显存/内存和基础生成参数。
- 优云库存与价格使用后端实时查询结果；接口失败时必须显示明确错误，不得显示为无限加载。
- 创建只保存配置快照，不创建实例、不启动服务。
- 配置保存后可查看完整参数，包括模型 Repo ID、Adapter lineage、镜像、采样参数、尺寸、步数和资源选择。
- 服务启动前再次校验模型、镜像、资源快照和生成参数；真正启动属于阶段二。

## 数据与接口契约

阶段一新增接口应保持与现有 `/api/datasets`、模型资产和推理服务接口风格一致：

- `POST /api/image-generation/datasets`：创建并校验文生图数据集。
- `GET /api/image-generation/datasets`：列出数据集及校验摘要。
- `GET /api/image-generation/models?provider=youyun`：返回可选基座模型和 Adapter。
- `GET /api/image-generation/youyun/gpu-specs`：返回推理用途的镜像、库存和区域快照。
- `POST /api/image-generation/services`：保存服务配置，不执行启动。

如果已有通用数据集或模型接口能够满足契约，优先扩展现有接口而不是复制存储逻辑；文生图特有字段通过明确的 `datasetType`、`modelType` 和 `trainingMode` 表达。

## 参数边界

- 默认尺寸先限制为常用范围，宽高必须为正整数并通过总像素上限校验。
- 采样步数、CFG、批大小、Seed、采样器使用后端类型和范围校验。
- LoRA 默认训练配置与 QLoRA 配置分开保存，不能通过前端传入任意量化参数绕过白名单。
- QLoRA 不作为所有模型的通用承诺；只有镜像探针和模型白名单同时通过时才可选。

## 阶段二预留

- 优云优先使用预置 Diffusers/ComfyUI 镜像。
- 镜像或模型未命中时，按服务端配置使用 ModelScope/Hugging Face 下载兜底。
- 生成任务使用异步任务记录，保存日志、进度、结果图和远端实例清理状态。
- 优云实例创建、启动、停止和失败清理必须复用视觉理解服务的资源生命周期约束。

## 测试与验收

- 前端测试覆盖数据集选择、Caption 编辑、模型分组、LoRA/QLoRA 可选状态和服务配置预览。
- 后端测试覆盖图片校验、metadata 生成、路径穿越防护、参数范围、模型/Adapter lineage 和服务创建不启动实例。
- 运行 TypeScript、Python compileall、前端测试、后端相关单元测试和 `git diff --check`。
- 浏览器验收阶段一页面：上传、预览、校验失败、发布、模型选择和优云资源快照均可见；不得触发真实 GPU 实例。

## 不做事项

- 不在本机启动 Diffusers、ComfyUI 或文生图 GPU 服务。
- 不在阶段一创建真实优云实例。
- 不做全参数微调、公开 API、自动扩缩容、多 GPU 调度和业务空间权限隔离。
- 不把 QLoRA 作为未经验证的默认路径。
