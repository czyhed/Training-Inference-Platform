# 优云社区镜像获取与验证设计

## 目标

发现优云社区镜像的真实 `CompShareImageId`，完成可用性探针后，向视觉理解和文生图训练页面提供可安全选择的镜像；没有合适社区镜像时，支持从可发布基础镜像构建并发布自有社区镜像。

## 约束

- 不允许根据社区名称猜测或拼接计费镜像 ID。
- 未完成探针的镜像只能展示，不能提交训练。
- 探针实例必须显式确认、设置硬性 TTL、失败自动释放并核验不存在。
- 现有平台镜像选择、训练接口和用户已有数据保持兼容。

## 架构

`YouyunClient` 新增社区镜像发现方法，调用优云社区镜像 API 并将分页、版本、状态、价格和 GPU 支持统一为平台目录结构。FastAPI 提供社区目录查询接口，前端合并平台镜像与社区镜像并展示验证状态。探针服务复用现有一次性实例管理器，运行最小依赖和前向检查后写入短期验证缓存；训练提交只接受真实 ID 且状态为 `verified` 的社区镜像。

## 回退路线

若社区 API 未返回满足条件的镜像，使用 `cuda132_torch2130_py312` 构建带 LLaMA-Factory/Qwen-VL 或 Diffusers 的私有镜像，完成验证后再通过优云控制台发布到社区。发布前清除密钥和缓存，保留构建清单与探针日志。

## 验收

- 能查询并展示社区镜像版本及真实 `CompShareImageId`。
- 无 ID、无库存、审核中或探针失败的镜像不可选择。
- 探针成功后视觉理解和文生图训练均能通过服务端镜像校验。
- 探针失败、超时或依赖缺失时实例自动释放且无残留。
- 目录查询失败时不影响现有平台镜像选择。
