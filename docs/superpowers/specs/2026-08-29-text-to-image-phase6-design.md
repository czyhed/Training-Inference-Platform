# 文生图阶段六设计

## 目标

在阶段五运行遥测与故障诊断的基础上，完善文生图推理服务的历史与结果管理闭环。用户可以按任务或服务查看生成记录，复制历史任务并编辑后重新生成，归档和恢复历史任务，并在不启动真实优云实例的情况下完成本地 Fake 验证。

## 范围与边界

- 复用现有文生图任务运行时、任务目录和结果接口，不新建独立结果存储系统。
- 仅保存和管理已经生成的本地结果文件；不在本阶段接入 MinIO 结果归档或对象生命周期策略。
- 任务创建、克隆、归档和恢复都不申请优云实例；只有用户确认任务时才进入现有优云运行链路。
- 本阶段不启动本机 GPU、Diffusers、SSH 或真实优云实例，全部通过 Fake Provider、API 测试和前端源代码测试验证。

## 数据模型

现有文生图任务记录增量增加：

- `archived: boolean`：是否归档，默认 `false`。
- `archivedAt: string | null`：归档时间，未归档为 `null`。

结果元数据继续存放在任务记录的 `results` 列表中，每项至少包含结果 ID、文件名、宽高、Seed、创建时间和本地路径。任务目录仍由 `resultRoot` 指向，结果文件不移动。

克隆任务保存完整的服务配置快照、模型和 Adapter lineage、生成参数与原任务关联信息；原任务保持不变。克隆结果为空，状态为 `awaiting_confirmation`，不会复用原任务的运行状态或优云实例句柄。

## 后端接口

### 任务历史

扩展 `GET /api/image-generation/tasks`，支持以下可选筛选：

- `serviceId`
- `state`
- `query`（任务名称或 Prompt）
- `includeArchived`

默认不返回已归档任务，保持现有调用方行为。接口可继续返回列表结构；如实现需要分页，响应中的任务项字段保持兼容。

### 克隆与重新生成

新增 `POST /api/image-generation/tasks/{id}/clone`。

- 仅允许读取存在的任务，包括已归档任务。
- 请求体允许覆盖 Prompt、Negative Prompt、宽高、步数、CFG、Batch Size、Seed 和采样器。
- 未提供的字段沿用原任务快照。
- 服务、基座模型、Adapter 版本和资源配置沿用原任务，但在创建时重新校验当前服务快照。
- 返回新的 `awaiting_confirmation` 任务。

### 归档与恢复

新增：

- `POST /api/image-generation/tasks/{id}/archive`
- `POST /api/image-generation/tasks/{id}/restore`

只有 `completed`、`failed`、`stopped` 状态允许归档。运行中状态禁止归档；已归档任务禁止确认、停止、重试或再次归档。恢复只改变可见性，不重新入队。

### 服务结果聚合

新增 `GET /api/image-generation/services/{service_id}/results`。

- 返回该服务关联的任务摘要和结果摘要。
- 支持 `state`、`query`、`includeArchived`、分页参数。
- 服务归档后仍允许只读查询历史结果。
- 结果下载继续通过现有 `/tasks/{task_id}/results/{result_id}` 接口，后端验证任务 ID、结果 ID、目录边界和 PNG 后缀。

### 删除与文件清理

删除任务前必须确认任务不在运行状态。删除成功时一并删除任务结果目录；文件系统清理失败时保留任务记录并返回明确错误，避免产生不可追踪的孤儿结果。单个结果不提供独立删除操作。

## 前端交互

### 任务历史页

- 增加服务、状态、关键词和是否包含已归档任务筛选。
- 默认隐藏已归档任务，并提供“已归档”视图。
- 任务详情继续展示阶段、诊断、结果和日志。
- 增加“复制并重新生成”：回填全部参数，用户编辑后创建新的待确认任务。
- 增加归档和恢复操作，并在归档前显示确认提示。
- 运行中任务隐藏归档入口；归档任务隐藏确认、停止、重试入口。

### 服务详情页

- 增加只读“生成历史”面板。
- 结果项显示缩略图、Prompt 摘要、参数、Adapter 版本、任务状态和时间。
- 支持打开原任务、下载结果和复制任务重新生成。
- 服务归档后可查看和下载历史结果，但不可创建新任务。

前端不直接拼接远端路径，图片始终通过后端结果接口访问；错误提示只展示后端安全文案，不渲染远端命令、路径或原始异常堆栈。

## 状态与错误处理

- 克隆任务继承配置，不继承结果、日志、遥测、失败码、清理状态或取消标记。
- 归档不改变任务运行状态、结果或诊断字段。
- 结果文件缺失时，任务和服务历史仍可查看，结果项标记不可用，其他结果继续可下载。
- 已归档任务被禁止执行动作时返回稳定的 `409` 错误；不存在的任务返回 `404`。
- 服务配置或模型 lineage 已失效时，克隆和重新生成在创建阶段返回现有安全校验错误，不申请云资源。

## 测试计划

### 后端

- 任务列表筛选和默认隐藏归档项。
- 服务结果聚合、分页、状态筛选和归档服务只读访问。
- 克隆任务的字段覆盖、默认继承、原任务不变和不入队保证。
- 归档/恢复的合法状态、非法状态拦截和幂等行为。
- 删除任务的结果目录清理及清理失败保留记录。
- 已归档任务的动作拦截和结果文件边界校验。

### Runtime

- 克隆快照不复制运行句柄或遥测字段。
- 归档任务不进入队列，恢复不自动入队。
- Fake 结果目录清理成功与失败路径。

### 前端与回归

- 筛选、已归档视图、复制编辑、服务结果面板和按钮禁用状态。
- 安全错误文案和缺失结果文件状态。
- 运行文生图 focused tests、`compileall`、TypeScript、前端测试、`git diff --check` 和生产构建。

## 不在本阶段

- 真实优云实例验收。
- MinIO 结果对象上传、跨服务共享和自动生命周期清理。
- 多用户权限、租户隔离和结果分享链接。
- 单张结果删除、批量任务操作和复杂图库编辑能力。
